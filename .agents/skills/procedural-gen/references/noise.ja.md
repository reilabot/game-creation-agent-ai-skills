# 地形、バイオーム、および散乱のノイズ

 勾配ノイズ (Perlin、Simplex、OpenSimplex) は、手続き型
地形の主力です。ノイズ関数は、連続 2D/3D 座標を滑らかな値にマッピングします。
グリッド全体でサンプリングすると、一貫したハイトフィールドが得られます。 **ライブラリを使用する** —
で正しい勾配ノイズを実装するのは面倒であり、価値があることはほとんどありません。

 エコシステム別ライブラリ: `FastNoiseLite` (C/C++/C#/Rust/JS/GLSL/HLSL、その他多くの 
)、`opensimplex` (Python)、`simplex-noise` (JS/TS)、`Unity.Mathematics.noise`
または`Mathf.PerlinNoise` (ユニティ)。出力範囲が異なることに注意してください。
 `0..1` を返すものもあれば、`-1..+1` を返すものもあります。結合する前に既知の範囲に再スケールします。

 ## 周波数と波長

 サンプリング `noise(freq * x, freq * y)` はパターンをズームします。周波数が高いほど機能が多く、
 機能は小さくなります。 `wavelength = map_size / frequency`。入力
座標 (例: `nx = x / width`) を常に正規化して、同じ周波数がマップ サイズ全体で同じ
を意味するようにします。

 ## オクターブ (フラクタル ブラウン運動)

 実際の地形には、大きな地形と小さな詳細が混在しています。オクターブの合計: 各オクターブ
は、周波数に **ラクナリティ** (通常 2.0) を乗算し、振幅に **ゲイン**
(別名パーシスタンス、通常 0.5) を乗算します。

```python
def fbm(noise, x, y, octaves=5, lacunarity=2.0, gain=0.5):
    total, amp, freq, norm = 0.0, 1.0, 1.0, 0.0
    for _ in range(octaves):
        total += amp * noise(x * freq, y * freq)
        norm  += amp
        amp   *= gain
        freq  *= lacunarity
    return total / norm        # divide by summed amplitude -> stays in 0..1
```

オクターブの独立性を保つ (原点付近の相関アーティファクトを避ける) には、
 に各オクターブに独自のシードを与えるか、
 `noise(2*x + 5.3, 2*y + 9.1)` のようにオクターブごとのオフセットを追加します。

 ## 再分布: 標高曲線の形成

 生の fBm は「すべての丘」です。関数 `e = f(e)`:

 - **谷/台地**: `e = pow(e, exponent)` と `exponent > 1` は、
 の中央の標高を平地に押し下げます。 `< 1` はそれらをピークに向かって引き上げます。
- **リッジ (山の棘)**: オクターブを合計する前の `r = 1 - abs(2*noise - 1)` (「リッジ」変換) 
。
- **テラス**: `e = round(e * levels) / levels` は個別のバンドにスナップします。

 これらは、写真の「カーブ」ツールと同じ画像フィルターのアイデアです。実験と
はファッジ係数を 1.0 付近に維持します (`pow(e * 1.2, exponent)`)。

 ## 2 つのフィールドからのバイオーム ルックアップ

 1 つのノイズ値がマップをバンド化します。非相関性のある 2 つの値により多様性が得られます。さまざまな種子から
**標高** と **水分** をサンプルし、テーブルルックアップします:

```python
def biome(e, m):
    if e < 0.10: return "OCEAN"
    if e < 0.12: return "BEACH"
    if e > 0.80:
        return "SNOW" if m > 0.5 else "TUNDRA"
    if e > 0.60:
        return "TAIGA" if m > 0.66 else "SHRUBLAND"
    if m < 0.16: return "DESERT"
    if m < 0.50: return "GRASSLAND"
    return "FOREST"
# These thresholds are starting points — every generator needs its own tuning.
```

## 島の形状

 マップ境界に水を強制的に配置するには、標高を距離ベースの
形状にブレンドします。中央からの `-1..+1` の `nx, ny` :

```python
# Square-bump distance: 0 at center, ~1 at edges.
d = 1 - (1 - nx*nx) * (1 - ny*ny)
e = lerp(e, 1 - d, mix)        # mix=0 -> original; mix~0.5 -> island
```

丸い島: `d = min(1, (nx*nx + ny*ny) / sqrt(2))`。海岸線のディテールを維持するために、島のシェーピングのみ
を低周波数オクターブに適用します。

 ## オブジェクト散乱 (木、岩)

 自然な間隔を保つために、高周波ノイズを**閾値にしない**。 **ポアソン
ディスク サンプリング** または **ジッター グリッド** を推奨します。これにより、最小間隔が保証され、
 の凝集が回避されます。密度を変化させるには、バイオームごとの最小半径を変更します (密集した
森林とまばらな砂漠)。

 ## ラップアラウンド (シームレス) マップ

 東のエッジが西のエッジとタイル状に並ぶマップの場合、円柱上のノイズをサンプリングします。
`x` を角度にマップし、`cos/sin` を 3D ノイズにフィードします。両方の軸のタイリングでは、トーラス上の 4D
ノイズを使用します。高次元のノイズは出力範囲が狭いため、後で
を再スケールします。

 ## 決定性チェックリスト

 - フ​​ィールドごとに 1 つのシード済みノイズ ジェネレーター。セーブに保存されます。
- 時間、フレーム、またはハッシュでランダム化された入力フィード生成はありません。
- 同じエンジン + 同じライブラリ バージョン = 同じ出力 (注:
ライブラリのスイッチング ノイズにより、同じシードでも結果が変わります)。
