# フィードバック レシピ — `game-feel` の深さ

 `game-feel` 本体の詳細はここにあります: シェイク計算、イージング チート シート、残りの
フィードバック メニュー (ノックバック、フラッシュ、ナンバー ポップ、フリーズ)、重要度レベルのプリセット、およびトゥイーンとエンジンごとの
バインディング粒子。すべてのスニペットは **Godot 4.7** および **Unity 6.3 LTS** をターゲットとしています。

 ## 1. トラウマ モデル (なぜ震えが気持ちいいのか)

 `[0, 1]` 内の単一の `trauma` 値を追跡します。出来事はトラウマを**追加**します。各
フレームで直線的に**減衰**します。実際の揺れの量は `trauma^2` (または `trauma^3`) なので、次のようになります。

 - 小規模/頻繁なイベントは画面をほとんど動かさない (トラウマが少ない、2 乗→極小)、
- 大きなイベントが激しくパンチする (トラウマが高い、2 乗→フルに近い)、
- トラウマが減衰するため、揺れは **常に自然に終了します** 0.

 オフセットと回転は `max_* * shake * noise(t)` です。時間をかけてノイズ関数または合計正弦
をサンプリングします。フレームごとに新しい `rand()` をサンプリングすることはありません。これにより、揺れの代わりに耳障りな騒音が生成されます。

```gdscript
# 1D value-noise-ish sampler without an addon: layered sines at incommensurate rates.
func _shake_axis(seed: float, t: float) -> float:
    return 0.6 * sin(t * 11.0 + seed) + 0.4 * sin(t * 23.0 + seed * 2.0)
```

調整可能な開始点: `max_offset = (8..16, 6..10) px`、`max_roll = 0.05..0.12 rad`、
 `decay = 1.0..1.5` 外傷/秒、ヒットごとの外傷 `0.15` (軽い) → `0.8` (重い)。

 ## 2. イージング チート シート — どのジョブにどのカーブを対応させるか

 |目標 |簡単 |ゴドー `Tween` |メモ |
|------|------|------|------|
| UI/要素を「ポップ」イン |オーバーシュート | `TRANS_BACK`、`EASE_OUT` |ターゲットを越えて射撃し、戻ってくる |
|弾む元気な土地 |バウンス/弾性 | `TRANS_ELASTIC`/`TRANS_BOUNCE`、`EASE_OUT` |控えめに使用してください。漫画のように読めます |
|安定/減速 |イーズアウト | `TRANS_CUBIC`/`TRANS_QUAD`、`EASE_OUT` | 「静止する」のデフォルト |
|予想/ワインドアップ |イーズイン | `TRANS_CUBIC`、`EASE_IN` |素早い行動の前にゆっくりスタート |
| A→B両端を滑らかに |イーズインアウト | `TRANS_SINE`、`EASE_IN_OUT` |カメラの移動、メニューのスライド |

 Unity 6.3 LTS には組み込みのトゥイーン ライブラリがありません。優先順位のオプション: `Vector3.SmoothDamp`
(春のようなフォローの場合)、`Mathf.SmoothStep`/コルーチンのハンドロールの容易さ、アニメーター カーブ、
、またはプロジェクトで既に使用されている場合はサードパーティのトゥイーン パッケージ。ツールに関係なく、*カーブの選択*
を同じにしてください。

```csharp
// Unity 6.3 LTS: a minimal eased scale "pop" in a coroutine (no external deps).
IEnumerator Pop(Transform t, float dur = 0.18f) {
    t.localScale = new Vector3(1.3f, 0.7f, 1f);            // squash on the event
    for (float e = 0; e < dur; e += Time.deltaTime) {
        float k = e / dur;
        float back = 1f + 2.7f * Mathf.Pow(1 - k, 2) * (k - 0); // overshoot-ish
        t.localScale = Vector3.Lerp(t.localScale, Vector3.one, k * k);
        yield return null;
    }
    t.localScale = Vector3.one;
}
```

## 3. 残りのフィードバック メニュー

 - **フラッシュ:** ヒット時に 1 ～ 3 フレームの間スプライト/マテリアルを白に着色し (`modulate`/マテリアル カラー)、
 でトゥイーンして戻します。安い、非常に読みやすい。
- **ノックバック:** ノーマル、クランプ、ショートのヒットから離れたところにインパルスを適用します。
`physics-tuning` を独自の安定性にしましょう。長いロックアウトではなく、短いコントロール ロックアウトと組み合わせてください。
- **数値/テキスト ポップ:** 増加、フェード、および緩和するダメージ数値を生成します。
の水平方向のドリフトをランダム化して、積み重ねられたヒットが扇状に広がるようにします。
- **粒子:** 接触点での短いバースト (火花、粉塵、破片)。それらをプールします
(`performance-optimization`) — ヒットごとにインスタンス化して解放しません。
- **フリーズフレーム:** 本体のヒットストップ。継続時間を重要度にスケールします (0.04 秒の軽度 →
0.15 秒の重度)。オプションで、世界全体ではなく、攻撃者とターゲットのみをフリーズします。
- **予想とフォロースルー:** 大きなアクションの前の小さなワインドアップと、
 を重みとして読んだ後の落ち着き。これはアニメーションであり、コード (エンジン アニメーション スキル) ではありません。
- **クロマティック/▒ビネット/ズームパンチ:** 重要な瞬間のための後処理ナッジ。短くしてください。

 ## 4. 重要度の段階 (ゲーム全体の比例を保つ)

 3 つのプリセットを定義し、すべての重要なイベントを 1 つに割り当てます。これは、
 が死んでいる (ジュース不足) か疲れている (すべてが最大になっている) と感じるのを防ぐものです。
|
|階層 |トラウマ |ヒットストップ |粒子 |番外編 |イベントの例 |
|------|:------:|:--------:|:---------:|----------|--------------|
|小さい | 0.10～0.20 |なし | 0–4 |チックSFX |足音、UI ホバー、コイン |
|中 | 0.30～0.50 | 0.04 ～ 0.06 秒 | 6–12 |フラッシュ |ノーマルヒット、ジャンプランド、ピックアップ |
|大 | 0.70～1.00 | 0.10 ～ 0.15 秒 | 20～40 |フラッシュ + ズーム + 数字 |クリティカル、ボスヒット、死亡、爆発 |

 ## 5. アクセシビリティ (これらのトグルを同梱)

 - **画面の揺れを軽減** (外傷出力を 0 ～ 100% の設定でスケールし、デフォルトは ~60 ～ 80%)。
- **フラッシュを軽減/無効にする** (感光性) — 白いフラッシュを静的な色合いに置き換えます。
- **カメラの動きを減らす** — シェイク ロールとズーム パンチをカットします。

 これらは、`game-ui-ux` (設定メニュー) および `input-systems` (アクセシビリティ セクション) とペアになります。

 ## 6. エンジンごとのバインディングの概要

 - **Godot 4.7:** `create_tween()` + `tween_property().set_trans().set_ease()`; `GPUParticles2D/3D`
ワンショット。 `Engine.time_scale` + `ignore_time_scale` タイマー; `Camera2D.offset`でシェイク。
- **Unity 6.3 LTS:** コルーチン + `SmoothDamp`/カーブ (またはトゥイーン パッケージ); `ParticleSystem.Play()`;
`Time.timeScale` + `WaitForSecondsRealtime`; `CinemachineBasicMultiChannelPerlin` を介したシェイク `trauma^2` によって駆動される
振幅/周波数 (`camera-systems` を参照)。
- **Web (Phaser/Pixi/three):** エンジン/ライブラリ トゥイーン経由のトゥイーン。 `this.cameras.main.shake()`
(フェイザー) `requestAnimationFrame` 主導のイーズが他の場所で行われます。
