# ペーシング、フロー、指導、ガイダンス

 ジオメトリは媒体です。目標は感じられるリズムです。このリファレンスでは、
 カーブ、ティーチング ループ、プレーヤーのガイド、ブロックアウトのレビューについて詳しく説明しています。

 ## 難易度/緊張度曲線

 進行状況に対して意図した強度をプロットします。 2 つの原則:

 - **局所的な落ち込みを伴う全体的な上昇。** 難易度と緊張感は
クライマックスに向けて上昇する傾向にありますが、*のこぎり波*: スパイク (戦闘、プラットフォーミング ガントレット、ボス)
は休憩 (探索、ストーリー、セーフ ルーム) で区切られています。単調なハイフラットライン
はプレイヤーのストレス反応を表します。単調な低音は退屈です。
- **クライマックスの前に休憩します。** 最も激しいビートの直前に、セーブ ポイント、展望台、
 リソース キャッシュなどの休憩時間を設けます。静けさがスパイクを鋭くする。

 便利なリズム: **イントロデューシング → ビルド → ピーク → リリース → (繰り返し、より高く) **。各
サイクルのピークは最後のサイクルを超えます。各リリースは、以前の
ベースラインをわずかに上回っています。

 ## ティーチング ループ (メカニックの紹介)

 プレイヤーは、安全性からステークスへのエスカレーションで、実践しながら学びます:

 1. 失敗しても無害な個別のメカニックを **紹介**します (目に見えて踏み越えることができるスパイク 
、敵が現れる)まだあなたを傷つけることはできません）。
2. **開発** — プレーヤー
が意図的に練習できるように、動きや 2 番目の要素と組み合わせます。
3. **ツイスト** — 記憶したモーションではなくアイデアを適用できるようにコンテキストを変更します。
4. **テスト** — 時間と健康のプレッシャーの下で、スキルが本当に重要な場合。

 これが、最初の部屋が穏やかで、ボスが最後にある理由です。レベルは * レッスン * です。
計画。新しいメカニックは、致命的なテストの前ではなく、テスト中には決してプレイヤーに遭遇しません。

 ## クリティカル パス、ゴールデン パス、および分岐

 - **クリティカル パス**: スタートからゴールまでの最小限のルート。順番に取得できるアビリティ/キーで常に
を解決できる必要があります (検証します)。
- **ゴールデン パス**: ほとんどのプレイヤーが実際に通るルートです。単に最短のラインではなく、
 に沿ってペースを設計してください。
- **分岐**: 探索と報酬のためのオプションのループ。勢いを失うことなく黄金の道に再び参加できるように、
 を十分に短くしてください。遠回りしたご褒美に。

 ループとショートカット (ドアのロックを解除して前のハブに戻る) により、後戻りによる疲労が軽減され、空間に一貫性が感じられます。

 ## ゲート ツール

 - **ロックとキー** — 明示的で読み取り可能な順序制御。
- **アビリティ ゲート** — キャズムには後で見つかるダブル ジャンプが必要です。再度アクセスすると、
 が開きます (メトロイドヴァニア パターン)。取得順序を検証します。
- **一方通行のドロップ/パスの崩壊** — 方向を強制します。
プレイヤーが故意に選択できるように電報を送ります。
- **ソフト ゲート** —
には硬い壁が「まだ」ないことを示唆する敵、環境上の危険、または困難。

 ## 読みやすさとガイダンス (壁のないリード)

 プレーヤーはサインではなく注意に従います。

 - **光とコントラスト** — 明るい出入り口には「ここに行ってください」と表示されます。シャドウは
として読み取られ、オプションまたは危険です。
- **リーディング ライン** —
の目標を指すアーキテクチャ、レール、およびパス。
- **ランドマーク** — 遠くからでも見える背の高いユニークなシルエットは、レベル全体にわたってプレイヤー
の方向を示します。
- **色と素材** - 「インタラクティブ/終了」の一貫した色は、
 プレーヤーにそれをスキャンするように指示します (登れる棚が同じ色相で塗装されているなど)。
- **フレーミング** — プレーヤーが下降する前に、高い地点
から次のゴールが見えるようにビューを構成します。

 プレイヤーがプレイテストで道に迷った場合、解決策となるのは通常、壁ではなく誘導 (視線、
 ライト) です。

 ## 2D と 3D の考慮事項

- **2D**: タイル グリッドとカメラ ウィンドウで考えます。プレーヤーには固定の
スライスが表示されます。画面外の脅威 (音声、接近時間) を電信するため、攻撃が公平に感じられます。
見通しと到達可能なプラットフォームの間隔が重要です。
- **3D**: 視線、垂直性、ナビゲーションを考慮してください。プレイヤーは 3 次元で
迷う可能性があります。ランドマークや額装された景色の方が重要です。カメラに注意してください —
狭い室内とプレーヤーのビュー コーンにより、知覚的に「到達可能な」範囲が変化します。

 ## ブロックアウト レビュー チェックリスト

 - クリティカル パスは、利用可能なキー/機能を *順番に* 使用して解決可能です (
 ソフトロックはありません)。
- メトリクス内で必要なすべてのジャンプ/トラバース (`SAFE_GAP`、リーチ、カメラ)。
- ペーシングは上昇ノコギリ波として読み取られます。各主要なスパイクの前に休憩が入ります。
- 各メカニズムはテストされる前に安全に導入されます。
- 目はパス (光/線/ランドマーク) に誘導されます。 「失われた」かどうかのテスト。
- オプションのコンテンツは、寄り道に報酬を与え、スムーズに再参加します。
- テクスチャなしのジオメトリもうまく再生します。ドレッシングをしても悪いレイアウトは救われません。
- デザイナーだけでなくプレイヤーも含めて検証済み。
