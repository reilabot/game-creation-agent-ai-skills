# Contributing

1. Keep every Skill in its own directory with a valid `SKILL.md`.
2. Preserve Progressive Disclosure and avoid duplicate responsibilities.
3. Add or update Router fixtures for observable routing changes.
4. Run `python scripts/validate_stack.py` before submitting changes.
5. Record external source revision, license, destination, and update procedure.
6. Never add secrets, proprietary SDK content, or unlicensed assets.

Changes to engine support, language selection, routing, or quality gates should explain the decision and include a representative fixture.
