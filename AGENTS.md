# Repository agent instructions

- For substantial game work, begin with `.agents/skills/game-studio-director/SKILL.md` and route through `.agents/skills/gamedev-router/SKILL.md`.
- Detect the engine and versions from repository evidence. Select one engine family and only the cross-cutting skills required by the goal.
- Keep simulation truth separate from presentation. Connect input, gameplay, animation, camera, VFX, audio, haptics, and accessibility with semantic events or explicit data contracts.
- Deliver a playable increment and validate it with `.agents/skills/gamedev-quality-gate/SKILL.md`.
- Do not publish, deploy, purchase, use credentials, or mutate production/player data without explicit approval at the point of action.
